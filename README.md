## About Dhruv-Drishti

Dhruv-Drishti is a location-based Augmented Reality visualization tool developed to enhance crevasse risk awareness during polar field operations. 
The tool enables users to visualize pre-detected crevasse locations in a real-world environment using a mobile device. 
Visual and audio warning signals are triggered when users enter predefined proximity zones, thereby improving situational awareness and safety near hazardous regions.
